# Numerical reference data — focal-plane polarization atlas

This directory contains **25 complex vector electric-field datasets** generated by [Tutorial 02 — Focal-Plane Polarization Atlas](../tutorials/02_Focal_Plane_Polarization_Atlas_PyVista.ipynb), Section 6, in the [TightFocusingSolutions](https://github.com/mffg1993/TightFocusingSolutions) repository.

The data are **high-resolution numerical references for one specific focusing configuration**, not exact analytical fields, experimental measurements, or a comprehensive validation of polarization singularities. They are intended for comparisons, reproducibility studies, code testing, and plotting without rerunning the full high-resolution integrals.

[Open Tutorial 02 in Colab](https://colab.research.google.com/github/mffg1993/TightFocusingSolutions/blob/main/tutorials/02_Focal_Plane_Polarization_Atlas_PyVista.ipynb)

## What is included?

| Files | Description | Count |
| --- | --- | ---: |
| `Gaussian_{H,V,D,A,R,L}.npz` | Gaussian inputs with six homogeneous Jones polarizations | 6 |
| `LG_plus1_{H,V,D,A,R,L}.npz` | `p=0` Laguerre–Gaussian-like inputs with azimuthal charge `+1` | 6 |
| `LG_minus1_{H,V,D,A,R,L}.npz` | `p=0` Laguerre–Gaussian-like inputs with azimuthal charge `-1` | 6 |
| `CV_{Radial,Azimuthal,Hyperbolic_X,Hyperbolic_Y}.npz` | Four cylindrical-vector input configurations | 4 |
| `FP_{Star,Monstar,Lemon}.npz` | Three full-Poincaré input constructions, named as in Tutorial 02 | 3 |
| [`convergence.csv`](convergence.csv) | Complex-vector errors of coarser integrations against the numerical reference | 1 |
| [`metadata.json`](metadata.json) | Parameters, conventions, software versions, and case names | 1 |

**Total: 25 NPZ datasets.** The full-Poincaré labels identify the incident constructions used by Tutorial 02; their names alone do not certify the topological classification of the *focused* field at a particular observation point.

## Physical and numerical parameters

These values come from the accompanying [metadata](metadata.json):

| Parameter | Value |
| --- | --- |
| Numerical aperture | `NA = 0.85` |
| Medium refractive index | `n_medium = 1.0` |
| Vacuum reference wavelength | `lambda0 = 1.0` (length units) |
| Focal length | `f = 1.0` (same length units) |
| Axial plane | `z = 0` |
| Cartesian sampling | `121 × 121` points |
| Reference polar quadrature | `1601` angular samples |
| Reference radial integration grid | `2001` nodes |
| Method | Five radial Bessel integrals; Simpson quadrature; linear radial interpolation |
| Pupil radial envelope | `q**abs(ell) * exp(-q**2)`, with `q = sin(theta)/sin(alpha)`, `alpha = asin(NA/n_medium)` |
| Time convention | `exp(-i omega t)` |
| Global lens phase | Constant `exp(-ikf)` omitted |
| Input-power normalization | **Not** normalized to equal incident power |

The coordinate arrays are in the same length units as `lambda0`. With `lambda0 = 1`, the coordinates can be interpreted numerically in units of the reference vacuum wavelength.

These files describe an **ideal, homogeneous-medium, aplanatic focusing calculation**. They do not model lens aberrations, layered media, interfaces, or experimental noise.

## Data schema and loading

Each NPZ file contains:

- `E`: complex128 array with shape `(3, 121, 121)`, indexed as `(component, y, x)`.
- `Ex`, `Ey`, `Ez`: convenient duplicates of `E[0]`, `E[1]`, and `E[2]`.
- `x`, `y`: 1D Cartesian coordinate arrays; `z`: focal-plane coordinate.
- `ell`: incident vortex charges and `jones_coefficients`: complex coefficients of the constituent input modes.
- `NA`, `n_medium`, `lambda0`, `focal_length`, `n_theta`, and `n_radial`: parameters and integration resolution.

Example, when run from the **repository root**:

```python
import numpy as np
import matplotlib.pyplot as plt

with np.load("reference_data/FP_Lemon.npz", allow_pickle=False) as data:
    E = data["E"]       # component order: Ex, Ey, Ez
    x, y = data["x"], data["y"]

assert E.shape == (3, len(y), len(x))
intensity = np.sum(np.abs(E)**2, axis=0)

plt.figure(figsize=(5, 4))
plt.pcolormesh(x, y, intensity, shading="auto")
plt.gca().set_aspect("equal")
plt.xlabel(r"$x/\lambda_0$")
plt.ylabel(r"$y/\lambda_0$")
plt.colorbar(label=r"$|E_x|^2+|E_y|^2+|E_z|^2$ (a.u.)")
plt.tight_layout()
plt.show()
```

The stored fields are **complex**, including their phase conventions. When comparing against another solver, match the optical parameters, Jones and vortex conventions, focal-plane coordinates, and global phase; do not independently normalize each component to force agreement.

## Numerical convergence

[`convergence.csv`](convergence.csv) compares the complete complex fields at the **same 121 × 121 output grid** against the highest-resolution calculation. Its metric is

```text
relative_complex_error = || E_candidate - E_reference ||_2 / || E_reference ||_2
```

The norm includes all three vector components and all sampled positions, with no arbitrary phase alignment.

| Calculation | Angular samples | Radial nodes | Largest error across 25 fields |
| --- | ---: | ---: | ---: |
| Default atlas | 401 | 251 | 8.98 × 10⁻⁵ |
| Intermediate | 801 | 1001 | 4.48 × 10⁻⁶ |
| Numerical reference | 1601 | 2001 | Reference baseline |

All 25 reported fields improve from the default to the intermediate resolution. **These are convergence measurements relative to the chosen numerical reference, not absolute error bounds or an independent proof of the optical model.** In particular, small global complex-field errors do not guarantee accurate director orientations in the immediate neighbourhood of field zeros or polarization singularities. For an independent two-angle Richards–Wolf check of the underlying focusing implementation, see [Tutorial 01](../tutorials/01_Thesis_Bessel_Integral_Decomposition.ipynb).

## Reproducing or extending the dataset

1. Open [Tutorial 02 in Colab](https://colab.research.google.com/github/mffg1993/TightFocusingSolutions/blob/main/tutorials/02_Focal_Plane_Polarization_Atlas_PyVista.ipynb).
2. Run its setup, optical-parameter, Jones/mode-definition, and five-integral solver cells.
3. Go to **Section 6 — Numerical reference dataset**; run Sections **6.1–6.3** to calculate all 25 fields, check convergence, and write the data and metadata.
4. Run **Section 6.4** to generate and download the ZIP archive. Alternatively, use the optional Google Drive commands.
5. For a different NA, wavelength, focal-plane grid, pupil envelope, or axial plane, change and document the parameters before generating a **separately identified dataset**. Do not overwrite this reference silently.

The original Colab calculation writes to `reference_data/z0_NA085/`. The files committed to this repository are stored **directly in this directory** for ease of use. The ZIP is a convenience for transfer; it is not required for loading individual fields from GitHub.
